주요 레이어

/src/api/
도메인별 Axios 서비스 모듈 (artistService.ts, roomService.ts, userService.ts 등). 모든 HTTP 요청은 axiosInstance.ts를 통해 처리 — 토큰 주입 · 401 자동 갱신 · /translate 엔드포인트 50초 타임아웃.
/src/store/
Zustand 스토어 2개.
useUserStore — 인증된 사용자 정보, 차단 유저 Set, 로그아웃; localStorage 커스텀 merge 영속화.
useArtistFollowStore — 팔로우한 아티스트 목록; 세션당 1회 지연 로딩.
/src/hooks/
데이터 페칭을 커스텀 훅으로 캡슐화 (React Query 미사용).
useArtistList — 무한 스크롤 + IntersectionObserver + 3회 재시도.
useChatSubscription — STOMP 구독.
useUserActivity — 15분 비활동 로그아웃 + 14분 토큰 갱신.
/src/pages/
라우트 단위 컴포넌트. 관리자 페이지는 /src/pages/AdminPage/ 하위.
/src/types/
공용 TypeScript 인터페이스. index.ts에 핵심 User / RecommendedUser 타입, 도메인 타입은 artist.ts, room.ts, chat.ts 등에 분리.
/src/socket.ts
STOMP 클라이언트 팩토리. VITE_API_BASE_URL을 변환(http → ws, /api → /ws-chat), 5초마다 재연결, 액세스 토큰을 쿼리 파라미터로 전달.

인증

토큰 저장

  • 액세스 토큰 → localStorage
  • 게스트 토큰 → sessionStorage
  • 리프레시 토큰 → HttpOnly 쿠키 (서버 관리)

토큰 갱신

  • Axios 인터셉터가 401 발생 시 자동 갱신
  • 갱신 실패 시 로그아웃 이벤트 발행
  • useUserActivity — 14분마다 선제적 갱신

게스트 유저

  • ID가 guest: 접두사로 시작
  • sessionStorage에 저장 (탭 닫으면 소멸)

OAuth2 흐름

  • 백엔드가 /oauth2/success로 리다이렉트
  • OAuth2RedirectHandler가 토큰 추출
💬

실시간 채팅

연결

  • WebSocket + STOMP via /ws-chat
  • 5초마다 자동 재연결
  • 액세스 토큰을 쿼리 파라미터로 전달

메시지 흐름

  • 구독: /topic/chat/{roomId}
  • 발행: /app/room/chat
  • 메모리에 최근 100개 메시지 유지

상태 관리 패턴

낙관적 업데이트

팔로우·차단은 서버 응답 전에 Zustand 상태를 먼저 업데이트하여 빠른 UX 제공.

이미지 URL 캐싱

유저 프로필 이미지 URL을 API 실패 대비 폴백으로 localStorage에 캐싱.

차단 유저 Set

채팅 메시지 필터링 시 O(1) 조회를 위해 Set<string>으로 blockedSet 관리.
