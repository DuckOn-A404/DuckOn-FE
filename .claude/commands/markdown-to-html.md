# markdown-to-html

주어진 마크다운 파일(또는 현재 프로젝트의 CLAUDE.md)을 읽어서, 내용에 맞는 **예쁜 다크 테마 HTML 위키 페이지**를 생성하고 브라우저로 열어라.

## 인자

`$ARGUMENTS` — 변환할 마크다운 파일 경로 (생략 시 현재 프로젝트 루트의 `CLAUDE.md` 사용)

## 동작 순서

1. `$ARGUMENTS`가 있으면 해당 경로, 없으면 현재 작업 디렉토리의 `CLAUDE.md`를 Read로 읽는다.
2. 파일 내용을 분석하여 섹션(헤더 레벨)과 구조를 파악한다.
3. 아래 디자인 원칙에 따라 HTML 파일을 생성한다. 출력 파일명은 입력 파일명에서 확장자를 `.html`로 바꾼다 (예: `CLAUDE.md` → `CLAUDE.html`, `wiki.md` → `wiki.html`).
4. 생성한 HTML 파일을 `open` 명령으로 브라우저에서 연다.
5. 생성된 파일 경로를 사용자에게 알린다.

## 디자인 원칙

- **다크 테마**: 배경 `#0f1117`, 카드 `#1a1d27`, 테두리 `#2e3250`
- **헤더**: 그라디언트 타이틀 + 기술 스택 badge-row (마크다운에서 추출 가능한 경우)
- **사이드바(sticky ToC)**: `#` 헤더를 자동으로 목차로 변환, 아이콘 포함
- **섹션별 카드 레이아웃**: `## 헤더` 마다 `<section>` 카드로 감싸고 아이콘 배지 부여
- **코드 블록**: ` ```bash ``` ` → 커맨드 카드 스타일 (좌: 명령어, 우: 설명)
- **테이블**: 줄 호버 하이라이트, 코드 셀에 accent 색상
- **반응형**: 768px 이하에서 사이드바 해제, 그리드 1열로 전환
- **폰트**: `Segoe UI / system-ui` (본문), `Consolas / Fira Code` (코드)
- **강조 색상**: accent `#6c8cff`, purple `#a78bfa`, green `#34d399`, orange `#fb923c`

## 마크다운 → HTML 변환 규칙

| 마크다운 요소 | HTML 처리 |
|---|---|
| `# 제목` | `<header>` 영역 타이틀 |
| `## 섹션` | `<section>` 카드 + 섹션 헤더 아이콘 |
| `### 소섹션` | 카드 내 소제목 |
| ` ```bash ``` ` | `.cmd-list` + `.cmd` 행 (명령어 / 설명 2열) |
| 일반 코드블록 | `<pre><code>` 다크 배경 블록 |
| 인라인 `` `code` `` | accent2 컬러 monospace span |
| 불릿 리스트 | `.info-card ul li` (▸ 아이콘) |
| 테이블 | hover 스타일 테이블 |
| 볼드 `**text**` | `font-weight:700` + 밝은 색 |
| 링크 `[text](url)` | accent 색상 링크 |

## 주의

- 외부 CSS/JS 라이브러리 없이 인라인 `<style>` 만 사용 (오프라인에서도 동작).
- 생성 파일을 `.gitignore`에 추가하지 말 것 — 사용자가 결정.
- 기존 동명 `.html` 파일이 있으면 덮어쓰기 전에 사용자에게 확인.
